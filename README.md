# FSC_Golden-Gate-Capstone
Financial Services Cloud capstone for Golden Gate Bank: household 360°, savings onboarding with Omnistudio, Action Plans and approvals, and secure Interaction Summaries with Interest Tags.

This project implements a Financial Services Cloud solution for a retail and investment banking scenario. It models Lakshmi’s household and accounts, uses Omnistudio for a guided savings account application on Residential Loan Application with Action Plans and branch approval, and adds Interaction Summaries with compliant sharing plus Interest Tags. The work follows an Agile, SPSM-style lifecycle with design artifacts and a demo-ready org.

Bullets (good for README “Overview”)
Scope: FSC household and relationship model, financial accounts and goals, rollups
Onboarding: Omnistudio OmniScript + Integration Procedures + data transforms; Action Plans (KYC checklist, branch tasks); approval and savings account creation
Trust & growth: Interaction Summaries, Compliant Data Sharing (MNPI), Interest Tags
Delivery: Discovery → design → build → test → demo (capstone methodology)
